# 🚀 عيّنة MD-Viewer (العربية)

مرحباً بك في **MD-Viewer** — قارئ ملفات Markdown سريع وبسيط لنظام Windows.

> هذا الملف لتجربة دعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار. لاحظ أن كل فقرة تحدد اتجاهها تلقائياً حسب محتواها.

## المقدمة

هذا التطبيق مصمم ليكون سريعاً وبسيطاً. يمكنك قراءة ملفات Markdown مباشرة دون الحاجة لفتح بيئة تطوير متكاملة مثل VS Code أو Cursor أو Antigravity.

الملف يُفتح دائماً في وضع **المعاينة** أولاً، لأن القراءة هي الهدف الأساسي — وليس التحرير.

## الميزات الرئيسية

- دعم كامل للغة **العربية** والإنجليزية معاً في نفس الملف
- تبويبات متعددة لفتح عدة ملفات في نفس الوقت
- التبديل بين المعاينة والكود بضغطة زر واحدة
- واجهة داكنة مريحة للعين بدون ألوان صارخة

## خطوات الاستخدام

1. افتح الملف بالسحب والإفلات داخل النافذة
2. أو اضغط `Ctrl + O` لاستعراض الملفات
3. استمتع بالقراءة!

## جدول الاختصارات

| الاختصار | الوظيفة |
|----------|---------|
| `Ctrl+O` | فتح ملف |
| `Ctrl+W` | إغلاق التبويب الحالي |
| `Ctrl+Tab` | التبويب التالي |
| `Ctrl+Shift+V` | التبديل بين المعاينة والكود |

## كود برمجي

كتل الكود تبقى دائماً باتجاه اليسار إلى اليمين لأنها كود:

```python
# التعليقات بالعربية تُعرض بشكل صحيح
def ahlan_ya_3alam() -> str:
    return "أهلاً بالعالم!"
```
